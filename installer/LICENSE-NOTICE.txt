WispWasp 0.1.0 - please read before installing

WHAT THIS IS
WispWasp listens to whatever your PC is playing, transcribes it, and
generates an image from the words. The newest image is shown on a page you
can capture in OBS.

WHAT IS NOT INCLUDED
This installer contains the app only, about 250 MB. It does not include:

  - ComfyUI, which does the image generation
  - PyTorch with CUDA support, roughly 3 GB
  - An image model, roughly 6.5 GB

Bundling those would make this a 10 GB download. Instead, the app opens on
a Setup page the first time you run it, and one button fetches all of it.
Nothing else needs installing first - no Python, no drivers beyond your
normal NVIDIA one. If the download is interrupted it carries on from where
it stopped rather than starting again.

If you already have ComfyUI, the app looks for it in the usual places and
uses it rather than downloading another copy.

WHAT YOU NEED
  - Windows 10 or 11, 64-bit
  - An NVIDIA GPU with at least 8 GB of video memory
  - About 22 GB of free disk space for the download and install

The speech model, about 250 MB, downloads by itself the first time you
start listening.

IF SOMETHING GOES WRONG
Run WispWasp.exe with --selftest. It checks each part and writes a
report to %USERPROFILE%\WispWasp\selftest.log that says which piece is
at fault.

UNSIGNED BUILD
This is not code signed, so Windows will probably show a blue
"Windows protected your PC" screen. Click "More info", then
"Run anyway". SmartScreen shows this for any installer it has not seen
before; it is not a report of anything found in the file.

PRIVACY
Everything runs on your machine. Audio is recorded in short clips, held
only long enough to transcribe, and overwritten by the next clip. Nothing
is uploaded anywhere unless you deliberately switch the image backend to
the online one in Settings.

A NOTE ON WHAT IT GENERATES
The app generates images from whatever it hears, and it will pick up voice
chat, videos and other people talking. If you set a "Style" in Settings,
it is appended to every prompt, including speech that happens to contain
real people's names. Be careful combining an explicit style with live
capture, particularly if you are streaming.

WHERE YOUR FILES GO
  Settings and overlay images:  %LOCALAPPDATA%\WispWasp
  Crash log, if it ever crashes: %USERPROFILE%\WispWasp\crash.log

Uninstalling removes the program but leaves your settings and images
alone.
